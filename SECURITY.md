# Security policy

## Scope and intent
RAVENCLAW is a governance-first security research platform.
If you discover a vulnerability in the repository, control plane, or runtime helpers, please report it privately rather than opening a public issue first.

## How to report
Until a dedicated security inbox is published, report through the operator-maintained private channel used for this deployment/repository.
If you are not sure which channel applies, do not publish exploit details in a public issue.

## What to include
Please include:
- affected file(s) / component(s)
- reproduction steps
- impact summary
- whether the issue affects only local deployment assumptions or also clean-environment/public-repo usage
- any suggested mitigation or patch direction

## Sensitive artifacts
Do not include live credentials, tokens, cookies, approval payloads, or private target data in public reports.
If redaction is needed, prefer a minimal proof of impact.

## Out of scope
This file does not grant permission for unauthorized testing against third-party systems.
Research and validation must remain authorized and within operator-approved scope.
