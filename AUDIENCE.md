# AUDIENCE.md

This file explains who Ravenclaw is for, who it is not for, and what expectations fit the current public repo.

## Who Ravenclaw is for

Ravenclaw is most relevant to people who care about one or more of these:
- governance-first security automation
- bounded autonomy in security workflows
- policy-gated execution design
- operator-facing control planes for semi-autonomous systems
- contract-oriented runtime architecture
- evidence and replayability in security research systems

In practice, that usually means:
- security researchers
- red-team or internal security engineering practitioners working in authorized contexts
- engineers studying agent governance and execution control
- technically serious readers evaluating architecture, contracts, and validation posture

## Who Ravenclaw is not for

Ravenclaw is not aimed at people looking for:
- a one-click offensive automation product
- an unconstrained offensive automation system
- a beginner-friendly security starter kit
- a polished consumer product or hosted service
- a proof-free hype repo built mainly around screenshots and claims

If someone wants instant spectacle or zero-context usability, this repo is currently the wrong fit.

## What the current public repo is best at

Today, the public repo is strongest as:
- an architecture and runtime design artifact
- a publishable governance-first public core
- a testable governance-first research codebase
- a controlled local dry-run demo surface
- a public record of how the system thinks about policy, contracts, operator truth, and the boundary between public core and private overlay

## What it is still improving

The repo is still improving in areas such as:
- public onboarding smoothness
- lowest-friction setup
- presentation polish for broader external audiences
- compression of a large technical surface into faster public comprehension

## Best-fit expectation

The best current expectation is:
Ravenclaw is a technical repo for readers who value governance, runtime correctness, inspectability, and clear public-boundary signals more than one-click automation.

## Short version

Ravenclaw is for technical readers who want bounded autonomy under governance.
It is not for people looking for a toy, an opaque system, or one-click security automation.
